About the service

Upload a comma-separated CSV containing Darwin Core Location information. BELS compares each record with a gazetteer of previously georeferenced biodiversity records and returns your original data with georeference results appended.

How matching works

If a record already contains a complete georeference, BELS retains it. Otherwise BELS searches for the best available match using progressively less coordinate information:

  1. locality information with decimal and verbatim coordinates;
  2. locality information with verbatim coordinates;
  3. locality information without coordinates.

See the User Manual for details about matching, field-name interpretation, and output fields.
